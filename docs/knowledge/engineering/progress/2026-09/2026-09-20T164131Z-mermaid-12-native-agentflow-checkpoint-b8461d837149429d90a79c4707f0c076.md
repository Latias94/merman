# Implemented

Commit `fb4981b5b` adds native Agentflow parsing and typed semantics, catalog registration, model resource
accounting, ELK/math capability admission and an independent family artifact that adapts into shared
Flowchart geometry. Compatibility JSON retains the domain semantic model (`vertices`, `subGraphs`,
`connectors`, diagnostics), while layout JSON uses `AgentflowDiagram`. Presentation metadata and parent
provenance are excluded from semantic JSON. ADR-0010 does not require every compatibility projection to
be the renderer getData IR; upstream getSemanticModel is the correct source for this projection.

The parser handles Unicode identifiers/labels, ordinary shape syntax, metadata blocks, domain edge kinds,
explicit/generated edge ids, nested flow/global declarations, connectors, local direction and basic
shape diagnostics. Unknown metadata remains opaque. Reserved upstream diagnostics are not invented.

The adapter carries collapsed-container context and pre-projects edges: collapsed-only false loops are
removed, authored self-loops survive, and crossing edges redirect to visible containers. Connector nodes
are rendered without being duplicated in semantic vertices. Agentflow kind palette classes and
container color slots follow source rules; expanded and collapsed containers retain their slot.

Bindings-core and WASM catalog tests now distinguish the non-detectable `flowchart` compatibility alias
from `flowchart-v2`, and assert Agentflow/Usecase parser and renderer facts. These are native catalog
checks, not evidence that the distributed WASM or Playground has been rebuilt.
