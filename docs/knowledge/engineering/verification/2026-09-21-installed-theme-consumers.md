# Reproduction and limits

Raw logs, local packages, installed consumers and exchange drivers are retained in
`target/bench/experiments/installed-theme-consumers-20260921/`. The source checkout and tool paths
are recorded in `context.json`; `environment.json` records versions and the untracked cache link.
Use the existing package owners in order:

1. Build the Python wheel with `scripts/build-python-uniffi-wheel.py --wheel-dir <new-directory>`;
   install it in a fresh venv and run `platforms/python/merman/examples/smoke.py`.
2. Install the locked Node and Web development dependencies, then run Node's `npm test` and
   `npm run check:packages`.
3. Run Node `build-candidate.mjs` for `napi --target darwin-arm64` and `node-wasm`, followed by
   their `assemble-packages.mjs` and `verify-packages.mjs --packed-root` commands.
4. Pack each group with npm 12, install offline with lifecycle scripts disabled in separate
   projects, and run `smoke-installed-package.mjs --project <consumer> --version 0.8.0-alpha.7
   --target <darwin-arm64|node-wasm>`.

Artifact sizes are current-source observations, not matched alpha.6 regressions or attribution
to the graph optimization. This record does not measure cold start, first render, throughput or
large-diagram memory. It does not qualify new preset cells, prove portable font appearance,
exercise binary exporters in these packages, verify registry installation, or execute other
Node/Python hosts and mobile consumers. C7a eligibility and the broader audit remain open.
