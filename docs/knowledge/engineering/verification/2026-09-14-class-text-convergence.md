Date: 2026-09-14

Source commit: `2a92c56b6a29eab4fc9dbe68fa1af6ac9de6bc1a`.

Default Solid/Transparent fill routes. The cutover replaces the historical node-label, title
and cluster-label projections. Class is removed from the executable legacy family dispatch;

NotApplicable. Partially shadowed rules preserve a winning supported facet and retain an
unsupported sibling residual. No ordinal, gradient, effect or unsupported mechanism was
promoted by this change.
