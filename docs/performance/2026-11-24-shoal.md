# Shoal layout benchmark · 2026-11-24

The nested Flowchart returned SVG in 0.501 ms with Shoal, 1.155 ms with Dagre, and 0.820 ms with ELK. The two-node control took around 0.13 ms with each backend. This comparison uses the same native release executable on one Apple M4 Pro with macOS 27.2.1 and Rust 1.100.0. [Source revision](https://github.com/Latias94/merman/commit/5b868946c30bf6a8f8a84c297b0477bed63f85e9) · [Measurement samples](2026-11-24-shoal.json) · [Use Shoal](../FEATURES.md#try-the-experimental-shoal-layout)

## Native latency

Each value is a median of 12 fresh processes with one warmup inside each process. Layout JSON times the public source-to-geometry operation and JSON writing. SVG times the public source-to-SVG call. Process startup and post-measurement validation are outside these intervals. The three backends receive the same input, configuration, and interactive resource profile.

| Flowchart | Dagre JSON (ms) | ELK JSON (ms) | Shoal JSON (ms) | Dagre SVG (ms) | ELK SVG (ms) | Shoal SVG (ms) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Two nodes | 0.065 | 0.078 | 0.061 | 0.142 | 0.138 | 0.121 |
| 12 nodes in six nested groups | 0.969 | 0.630 | 0.365 | 1.155 | 0.820 | 0.501 |
| 75 nodes with cycles | 3.700 | 11.246 | 0.791 | 4.444 | 12.574 | 1.341 |
| 100 nodes with cycles | 4.874 | Budget limit | 0.996 | 5.856 | Budget limit | 1.831 |
| Same 100-node graph, reverse edge declarations | 3.182 | 5.327 | 0.995 | 4.028 | 6.565 | 1.827 |
| 500 nodes, fan-in | 6.738 | Budget limit | 3.460 | 9.030 | Budget limit | 6.441 |
| 500 nodes, fan-out | 6.684 | 11.365 | 3.410 | 9.082 | 15.180 | 6.177 |

For each timed row, the completing backends agree on node and group identities, directed edge occurrences, marker ends, and painted labels. Each sampled SVG matches its backend's verified digest. The columns describe this workload and host, and the drawings use each engine's own placement and routes. [Validation and timing procedure](RUNBOOK.md#compare-native-flowchart-layouts)

## Coverage and heap use

| Corpus and resource profile | Dagre SVG | ELK SVG | Shoal SVG |
| --- | ---: | ---: | ---: |
| 32 stress topologies, interactive | 31 | 28 | 31 |
| 32 stress topologies, constrained | 16 | 4 | 18 |
| 36 statement-order variants, interactive | 36 | 30 | 36 |
| 36 statement-order variants, constrained | 4 | 0 | 15 |

The 500-node fork–join input hit the parser's edge limit for all three backends. Other omitted renders in these two corpora hit the layout work budget. For Shoal, reversing the edge declarations of `scc-100` changed charged SVG layout work from 156,999 to 158,252 units, a 1.0080× ratio.

The earlier heap run on the nested example measured a cumulative median of 2,828 KiB with Dagre, 1,460 KiB with ELK and 774 KiB with Shoal. The corresponding operation heap growth above the warmed baseline peaked at medians of 572, 236 and 208 KiB. Each figure uses five fresh samples from the instrumented SVG runner. ## Reproduce the native table

```sh
python3 tools/bench/perf_runner.py workloads plan --suite full \
  --scenario small-svg --scenario flowchart-nested-layout \
  --scenario scc-75 --scenario scc-100 --scenario scc-100-edges-reverse \
  --scenario fan-in-500 --scenario fan-out-500 --out target/bench/shoal-plan.json
python3 tools/bench/perf_runner.py workloads rust-layouts \
  --plan target/bench/shoal-plan.json --resource-profile interactive --warmups 1 --samples 12 \
  --out target/bench/shoal-comparison.json
```

`rust-layouts` writes all receipts, including the two interactive ELK budget rejections, and returns a nonzero status for incomplete comparisons.

## Shoal v3 follow-up

The follow-up uses an Apple M4 Pro with macOS 27.2.1 and Rust 1.100.0. Each native median uses 12 fresh processes and two warmups per process. Every timed SVG matched its backend's verified digest.
