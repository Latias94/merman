# Shoal layout benchmark · 2026-11-24

The nested Flowchart returned SVG in 0.541 ms with Shoal, 1.149 ms with Dagre, and 0.754 ms with ELK. The two-node control took around 0.13 ms with each backend. This comparison uses the same native release executable on one Apple M4 Pro with macOS 27.2.1 and Rust 1.100.0. [Source revision](https://github.com/Latias94/merman/commit/d334b34c855b0b5b8f1f03bd34f848b5c308d356) · [Measurement samples](2026-11-24-shoal.json) · [Use Shoal](../FEATURES.md#try-the-experimental-shoal-layout)

## Native latency

Each value is a median of 12 fresh processes with one warmup inside each process. Layout JSON times the public source-to-geometry operation and JSON writing. SVG times the public source-to-SVG call. Process startup and post-measurement validation are outside these intervals. The three backends receive the same input, configuration, and interactive resource profile.

| Flowchart | Dagre JSON (ms) | ELK JSON (ms) | Shoal JSON (ms) | Dagre SVG (ms) | ELK SVG (ms) | Shoal SVG (ms) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Two nodes | 0.065 | 0.077 | 0.058 | 0.125 | 0.137 | 0.127 |
| 12 nodes in six nested groups | 1.020 | 0.588 | 0.355 | 1.149 | 0.754 | 0.541 |
| 75 nodes with cycles | 3.526 | 11.111 | 0.767 | 4.830 | 12.238 | 1.421 |
| 100 nodes with cycles | 4.685 | Budget limit | 1.025 | 6.364 | Budget limit | 1.871 |
| Same 100-node graph, reverse edge declarations | 3.088 | 5.283 | 0.991 | 3.882 | 6.477 | 1.868 |
| 500 nodes, fan-in | 6.600 | Budget limit | 3.564 | 9.116 | Budget limit | 6.086 |
| 500 nodes, fan-out | 6.704 | 11.107 | 3.434 | 8.994 | 14.626 | 6.222 |

For each timed row, the completing backends agree on node and group identities, directed edge occurrences, marker ends, and painted labels. Each sampled SVG matches its backend's verified digest. The columns describe this workload and host, and the drawings use each engine's own placement and routes. [Validation and timing procedure](RUNBOOK.md#compare-native-flowchart-layouts)

## Coverage and heap use

| Corpus and resource profile | Dagre SVG | ELK SVG | Shoal SVG |
| --- | ---: | ---: | ---: |
| 32 stress topologies, interactive | 31 | 28 | 31 |
| 32 stress topologies, constrained | 16 | 4 | 18 |
| 36 statement-order variants, interactive | 36 | 30 | 36 |
| 36 statement-order variants, constrained | 4 | 0 | 15 |

The 500-node fork–join input hit the parser's edge limit for all three backends. Other omitted renders in these two corpora hit the layout work budget. For Shoal, reversing the edge declarations of `scc-100` changed charged SVG layout work from 160,861 to 161,934 units, a 1.0067× ratio.

On the nested example, the instrumented SVG runner allocated a cumulative median of 2,828 KiB with Dagre, 1,460 KiB with ELK and 774 KiB with Shoal. The corresponding operation heap growth above the warmed baseline peaked at medians of 572, 236 and 208 KiB. Each figure uses five fresh samples. [Heap samples](2026-11-24-shoal.json)

## Reproduce the native table

```sh
python3 tools/bench/perf_runner.py workloads plan --suite full \
  --scenario small-svg --scenario flowchart-nested-layout \
  --scenario scc-75 --scenario scc-100 --scenario scc-100-edges-reverse \
  --scenario fan-in-500 --scenario fan-out-500 --out target/bench/shoal-plan.json
python3 tools/bench/perf_runner.py workloads rust-layouts \
  --plan target/bench/shoal-plan.json --resource-profile interactive --warmups 1 --samples 12 \
  --out target/bench/shoal-comparison.json
```

`rust-layouts` writes all receipts, including the two interactive ELK budget rejections, and returns a nonzero status for incomplete comparisons.
