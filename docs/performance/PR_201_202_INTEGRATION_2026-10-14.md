## Architecture and behavior

The #201 repairs use the current compiled-theme and prepared-family interfaces. The retired
presentation compiler and Options 2 API are not restored. Family-owned Mermaid configuration
reaches C4, ZenUML, Wardley, Gantt, XYChart and Mindmap without repeated JSON reads in SVG writers.
Explicit source and site overrides retain their owners. Background and text remain independent
compiled-theme properties; unsupported targets are not silently promoted.

Ordinary HTML label fallbacks use isolated definitions referenced at their original paint
position. Transforms, nested viewports, clipping and opacity stay under the source ancestors.
Writer-owned background and glyph-filter evidence retains direct, inspectable terminals.
Local clip/mask/filter CSS references are parsed as complete declarations and stay restricted
to same-document fragments. The final resource and evidence checks remain fail-closed.
The historical before/after captures from #201 remain under
`docs/assets/presentation-issues-197-200/`, explicitly labelled with their source revisions and
retired API. Current API behavior is exercised by `host_render_contract`.
