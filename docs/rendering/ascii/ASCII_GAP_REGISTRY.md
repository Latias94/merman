# ASCII Gap Registry

Status: Active evidence registry
Last updated: 2026-11-18

This registry maps remaining ASCII renderer gaps to owning modules, dependencies, and validation
gates. It does not replace the support matrices:

- `FLOWCHART_SUPPORT.md` remains the shipped flowchart support boundary.
- `SEQUENCE_SUPPORT.md` remains the shipped sequence support boundary.
- `STATE_SUPPORT.md` remains the shipped state support boundary.
- `USECASE_SUPPORT.md` and `BLOCK_SUPPORT.md` own their admitted spatial subsets and diagnostics.
- [C4 support](C4_SUPPORT.md) owns its declaration-order overview and complete reading records.
- [ZenUML support](ZENUML_SUPPORT.md) owns its lifeline scene, control frames, and complete records.
- [Gantt support](GANTT_SUPPORT.md) owns its elapsed-time timeline and complete keyed records.
- `AGENTFLOW_SUPPORT.md`, `REQUIREMENT_SUPPORT.md`, and `PIE_SUPPORT.md` own their family projections.
- [Graph fixture gaps](../../../crates/merman-ascii/tests/testdata/mermaid-ascii/GRAPH_FIXTURE_GAPS.md)
  and [Sequence fixture gaps](../../../crates/merman-ascii/tests/testdata/mermaid-ascii/SEQUENCE_FIXTURE_GAPS.md)
  remain copied-fixture gap evidence.

Use this file as the first planning context for new ASCII workstreams.

Output decisions belong to the rendered candidate, not a second family inspection during report
construction. New family adapters must return their actual projection and document policy with
the text. Complete-record primaries share the retained composer: geometry stays indivisible,
records reflow to the requested width, live buffers are admitted together, and only the selected
document commits final cells. These contracts are covered by `layout_selection`, `reading_records`,
and the resource/encoding tests; they are not open work requiring another output framework.

## Closeout Discipline

When a gap is implemented:

- update the relevant support matrix first;
- update `crates/merman-ascii/src/capability.rs` when the public support level, limits, or evidence story changes;
- add or update tests named in the validation gate;
- record the closing workstream or commit in this registry;
- remove the gap only when shipped behavior is documented elsewhere.
