# merman-core-graph

Syntax parsing for Mermaid graph diagrams. The `diagram-er` feature parses entity–relationship
diagrams into canonical `merman-model` values. The `diagram-state` feature parses state diagrams
into a typed nested document. The `editor-facts` feature exposes lexical events for editor consumers.

Use `merman-core` to parse a complete Mermaid source and map diagnostics to the original input.
